# Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built with vanilla HTML, CSS, and JavaScript.

## Features

- Player picks rock, paper, or scissors
- Computer picks randomly
- Win/lose/draw logic and result shown on screen
- Score tracking across rounds

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript (DOM manipulation, event listeners)

## Running locally

No build step. Clone the repo and open `index.html` in a browser.

## What I learned building this

- Event handling with `addEventListener`
- Conditional logic for win/lose/draw comparisons
- Updating the DOM based on game state
- Basic use of `Math.random()` for the computer's choice
